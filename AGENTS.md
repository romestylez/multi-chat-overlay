# Repository instructions

## Branches in the open checkout

- Keep the shared, open repository checkout on its current branch. Do not create or switch to a `codex/*` task branch in this checkout.
- Use a managed worktree for isolated work that needs a separate branch. Do not move the open checkout to a task branch.
- Follow a user's explicit request when they specify a different branch or checkout behavior.

## GitHub Desktop handoff

- Leave repository changes uncommitted and unpushed for the user to handle through GitHub Desktop. Do not create branches, commits, pushes, or pull requests unless the user explicitly asks.
- When finishing repository changes, provide a suggested title and description the user can use in GitHub Desktop or a pull request.
- Always write the suggested title and description in English.
